# Demo gastronómica AppNova

Sitio estático para probar gestión de pedidos, platillos e inventario de sushi, comida rápida, pizzería, parrilla y comida variada. Los precios y productos incluidos son referenciales.

Abre `index.html` con un servidor estático. El selector **Tipo de local** cambia el catálogo y la identidad visual. Los platillos nuevos aparecen de inmediato en el menú y en Nuevo Pedido. La prueba guarda productos e inventario en `sessionStorage` de la pestaña; **Reiniciar prueba** elimina esos datos locales.

Esta rama no usa backend ni modifica la demo publicada. El diseño de persistencia futura se encuentra en [docs/persistencia-demo.md](docs/persistencia-demo.md) y [docs/schema-demo.sql](docs/schema-demo.sql).
